Section 6.1

HTML Audio

Use the <audio> tag to embed sound content in a document, such as music or other audio streams.

Common Attributes: controls, autoplay, muted, loop.

Code Example

<audio controls autoplay loop muted>
    <source src="file/Tujhe_Dekha_To.mp3" type="audio/mpeg">
    <source src="file/Tujhe_Dekha_To.ogg" type="audio/ogg">
    <source src="file/Tujhe_Dekha_To.wav" type="audio/wav">
    Your browser does not support the audio element.
</audio>

Section 6.2

HTML Video

The <video> tag is used to embed video content. You can set the width and height attributes, and even add a poster image that shows before the video plays.

Code Example

<video width="600" controls poster="thumbnail.jpg">
    <source src="video.mp4" type="video/mp4">
    <source src="video.ogg" type="video/ogg">
    Your browser does not support the video tag.
</video>

Section 6.3

HTML Iframe / YouTube Video

The <iframe> tag is used to embed another document within the current HTML document. It is commonly used to embed third-party media, such as YouTube videos, using the src, width, and height attributes.

Code Example

<iframe 
  width="100%" 
  height="315" 
  src="https://www.youtube.com/embed/cNV5hLSa9H8" 
  frameborder="0" 
  allowfullscreen>
</iframe>
