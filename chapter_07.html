Section 7.1

SVG Graphics

SVG stands for Scalable Vector Graphics and defines graphics for the web[cite: 106]. We use the <svg> element to define an SVG image[cite: 106].

7.1.1 SVG Rectangle

Code Example

<svg width="100" height="100">
    <rect x="10" y="10" width="80" height="60" stroke="#2563eb" stroke-width="2" fill="#f5a623" />
</svg>

7.1.3 SVG Ellipse

We use the <ellipse> element to draw an ellipse in an SVG image[cite: 108]. Its center will be at point (cx, cy), the rx attribute defines its horizontal radius, and ry defines its vertical radius[cite: 108].

Section 7.2

Canvas

The <canvas> element is used to draw graphics on a webpage via JavaScript[cite: 120]. By default, the canvas has no border and a transparent background so that we can place it in front of another element[cite: 120].

7.2.1 Draw Text

We use the drawing object to draw text on our canvas using the fillText() method[cite: 120]. We can also set a font for the text using the font property[cite: 120].

Code Example

<canvas id="my-canvas" width="200" height="100" style="border: 1px solid #e2e8f0; background-color: #f8fafc; border-radius: 8px;"></canvas>
<script>
  var c = document.getElementById("my-canvas");
  var ctx = c.getContext("2d");
  ctx.fillStyle = "#1c2540";
  ctx.font = "20px Arial";
  ctx.fillText("Neo D. Truman", 10, 50);
</script>

Visual Example

Browser Output Preview

7.2.2 Draw Lines

We get the drawing object from our canvas to draw a line using three methods: moveTo(x, y), lineTo(x, y), and stroke()[cite: 121].

Code Example

<script>
  var c = document.getElementById("my-canvas");
  var ctx = c.getContext("2d");
  ctx.strokeStyle = "#2563eb";
  ctx.lineWidth = 3;
  ctx.moveTo(0, 0);
  ctx.lineTo(200, 100);
  ctx.stroke();
</script>

Visual Example

Browser Output Preview

7.2.3 Draw Circles

To draw a circle, we use the arc(x,y,r,startangle,endangle) method and invoke the drawing with stroke(). The end angle is set to 2*PI.

Code Example

<script>
  var c = document.getElementById("my-canvas");
  var ctx = c.getContext("2d");
  ctx.strokeStyle = "#f5a623";
  ctx.lineWidth = 3;
  ctx.arc(95, 50, 40, 0, 2 * Math.PI);
  ctx.stroke();
</script>

7.2.5 Linear Gradient

We use the createLinearGradient(x1,y1,x2,y2) method to create a linear gradient[cite: 124]. The addColorStop() method specifies a color stop, and fillStyle applies it to the shape[cite: 125].

Code Example

<script>
  var c = document.getElementById("my-canvas");
  var ctx = c.getContext("2d");
  var grd = ctx.createLinearGradient(0, 0, 200, 0);
  grd.addColorStop(0, "#2a5bd7");
  grd.addColorStop(1, "#f5a623");
  ctx.fillStyle = grd;
  ctx.fillRect(20, 20, 160, 60);
</script>

7.2.6 Radial Gradient

We use the createRadialGradient(x1,y1,r1,x2,y2,r2) method to create a radial gradient[cite: 126].

Code Example

<script>
  var c = document.getElementById("my-canvas");
  var ctx = c.getContext("2d");
  var grd = ctx.createRadialGradient(60, 60, 10, 95, 50, 70);
  grd.addColorStop(0, "#f5a623");
  grd.addColorStop(1, "#16306b");
  ctx.fillStyle = grd;
  ctx.fillRect(0, 0, 200, 100);
</script>

7.2.7 Draw Images

We use the drawImage(image,x,y,width,height) method to draw an image on canvas at the point (x,y)[cite: 127]. If width and height parameters are not specified, the intrinsic size of the image will be used[cite: 127].

Code Example

<script>
  var c = document.getElementById("my-canvas");
  var ctx = c.getContext("2d");
  const image = new Image();
  image.onload = drawMyImage;
  image.src = "image/my_picture.png";
  
  function drawMyImage() {
    ctx.drawImage(this, 50, 0);
    ctx.drawImage(this, 0, 0, 80, 80);
  }
</script>
