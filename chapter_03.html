Section 2.2

HTML Paragraphs

Paragraphs are defined with the <p> tag. A paragraph always starts on a new line, and browsers automatically add some white space (a margin) before and after a paragraph.

Code Example

<p>This is a standard paragraph of text.</p>
<p>This is another paragraph.</p>

Visual Example

Browser Output Preview

Section 2.3

Hyperlinks

Links are created using the <a> (anchor) tag. The href attribute specifies the destination URL.

Code Example

<!-- External Link -->
<a href="https://www.google.com" target="_blank">Visit Google</a>

<!-- Internal Link (to another page) -->
<a href="about.html">About Us</a>

Visual Example

Browser Output Preview Visit Google About Us
Section 2.4

Images

Images are embedded using the <img> tag. It is a void element (no closing tag). The src attribute holds the image path, and alt provides alternative text.

Code Example

<img src="/image/my_picture.png" alt="my_picture" width="200px" Height="200px">

Section 2.5

Lists

HTML supports Unordered Lists (bullet points) and Ordered Lists (numbered).

Code Example

<!-- Unordered List -->
<ul>
    <li>HTML</li>
    <li>CSS</li>
</ul>

<!-- Ordered List -->
<ol>
    <li>Step One</li>
    <li>Step Two</li>
</ol>

Section 2.6

Tables

Tables are used to display data in rows and columns.

Code Example

<table border="1">
    <tr>
        <th>Name</th>
        <th>Role</th>
    </tr>
    <tr>
        <td>John</td>
        <td>Admin</td>
    </tr>
</table>

Visual Example

Breaks

Progress Bars

The <progress> tag represents the completion progress of a task.
