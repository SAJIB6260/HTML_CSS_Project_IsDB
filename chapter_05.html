Section 1.0

Images

Images are embedded using the <img> tag. It is a void element (no closing tag). The src attribute holds the image path, and alt provides alternative text.

1.1 Image Attributes (Sub-section)

Along with src and alt, you can also use width and height attributes to specify the size of the image.

Code Example

<img src="image.jpg" alt="Example" width="500" height="300">
