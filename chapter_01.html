Section 1.1

Two Types of HTML Elements

In HTML, there are primarily two types of elements you will use to structure your content:

1. Container Elements (Normal Elements)

These elements have an opening tag and a closing tag. They wrap around content (like text or other elements). 

<h1>Welcome to DotNet Pathshala</h1>
<p>Start your web development journey today.</p>

2. Void Elements (Empty Elements)

These elements do not have a closing tag because they cannot contain content. They are used for inserting things like line breaks or images. 

<hr> <!-- (Horizontal Rule) -->
<br> <!-- (Line Break) -->
<img src="logo.png" alt="Logo"> <!-- (Image) -->
Section 1.2

HTML Document Structure

Every modern webpage follows a strict structure (DOM) so that browsers and search engines can understand it properly. 

<!DOCTYPE html>
<html>
<head>
    <!-- Metadata, Title, CSS links -->
</head>
<body>
    <!-- Visible content (Text, Images, Buttons) -->
</body>
</html>
Section 1.3

Your First Webpage

Let's create a simple page. The <title> sets the name in the browser tab, and the <h1> is the main heading on the page. 

<!DOCTYPE html>
<html>
<head>
    <title>My First Site</title>
</head>
<body>
    <h1>Hello World!</h1>
    <p>This is my first paragraph.</p>
</body>
</html>

When you save this as .html and open it in Chrome, you will see a bold heading and a paragraph.

Section 1.4

Character Encoding

Character encoding dictates how text is processed. We declare it using the meta tag so symbols and foreign characters display properly. 

<meta charset="UTF-8">
Section 1.5

Element Attributes

Attributes provide extra information about elements. They are always specified in the opening tag. 

<a href="https://google.com" target="_blank">Visit Google</a>
Section 1.6

Favorite Icon

The favicon is a small icon shown next to your page title in the browser tab. 

<link rel="icon" type="image/x-icon" href="/favicon.ico">
Section 1.7

Comments

Comments are used by developers to leave notes for themselves or others. The browser completely ignores them.
