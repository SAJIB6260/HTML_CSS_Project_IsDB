Section 9.1

Window Events

HTML can let events trigger actions in a browser, like invoking a JavaScript function when users interact with the window[cite: 133].

9.1.1 onload

The onload attribute fired when the browser finished loading a webpage[cite: 133]. We usually handle the onload event on these elements: <body>, <iframe>, <img>, <link>, and <script>[cite: 133].

Code Example

<script>
  function eventHandler() {
    alert("Page is loaded");
  }
</script>
<body onload="eventHandler()">
  <h1>This is a heading</h1>
</body>

9.1.2 onresize

The onresize attribute fires when the browser window is resized[cite: 133].

Code Example

<script>
  function eventHandler() {
    alert("You have changed the size of your browser window!");
  }
</script>
<body onresize="eventHandler()">
  <h1>This is a heading</h1>
</body>

Section 9.2

Form Events

Form events are triggered when a user interacts with HTML form controls like text inputs, dropdowns, or radio buttons[cite: 135]. They are incredibly useful for validating user data, giving real-time feedback, and making forms much more interactive.

9.2.1 onfocus

The onfocus attribute fires the moment an element gets focused[cite: 135]. For example, when a user clicks inside a text box to start typing, or uses the "Tab" key to navigate to it, the field becomes "focused". This is often used to highlight the active input field by changing its background color[cite: 135].

Code Example

<script>
  function handleFocus(input) {
    input.style.background = "yellow";
  }
</script>
<body>
  First name: <input type="text" onfocus="handleFocus(this)" />
</body>

Visual Example

Browser Output Preview

9.2.2 onblur

The onblur attribute is the exact opposite of onfocus. It fires when the element loses focus[cite: 135]. If a user clicks outside the input field or tabs away from it, the blur event occurs. It is highly effective for instant form validation, such as checking if the entered email is valid right after the user leaves the field[cite: 135].

Code Example

<script>
  function handleBlur() {
    var x = document.getElementById("fname");
    alert("Hi " + x.value);
  }
</script>
<body>
  Enter your name: <input type="text" id="fname" onblur="handleBlur()" />
</body>

Visual Example

Browser Output Preview

9.2.3 onchange

The onchange attribute fires when the element's value has been fully changed and committed[cite: 136]. For dropdown menus (<select>), it triggers immediately after a new option is chosen. For text inputs, it triggers when the user finishes typing and leaves the box[cite: 136].

Code Example

<select id="my-select" onchange="eventHandler()">
  <option value="Audi">Audi</option>
  <option value="BMW">BMW</option>
</select>
<script>
  function eventHandler() {
    var x = document.getElementById("my-select").value;
    alert("You selected: " + x);
  }
</script>

Visual Example

Browser Output Preview

9.2.4 oninput

Unlike onchange which waits until you leave the field, the oninput attribute fires continuously whenever an element gets user input[cite: 136]. It tracks modifications character by character. This makes it perfect for live search filters, word counters, or dynamically updating text on the screen while the user is actively typing[cite: 136, 137].

Code Example

<p>Write some text into the box!</p>
<input type="text" id="my-input" oninput="eventHandler()" />
<p id="output"></p>

<script>
  function eventHandler() {
    var x = document.getElementById("my-input").value;
    document.getElementById("output").innerHTML = "You wrote: " + x;
  }
</script>

Section 9.3

Keyboard Events

Keyboard events allow you to capture and respond to user keystrokes[cite: 138]. They are essential for creating shortcuts, building games, filtering live data, or transforming input text in real-time as the user types.

9.3.1 onkeydown

The onkeydown attribute fires the exact moment a user presses a key down on the keyboard[cite: 138]. It triggers before the character is even typed into the field. This event is great for detecting special keys like "Enter", "Arrow keys", or catching shortcuts (like Ctrl+C).

Code Example

<p>A function is triggered when the user presses a key.</p>
<input type="text" onkeydown="eventHandler()" />

<script>
  function eventHandler() {
    alert("You pressed a key inside the input field");
  }
</script>

Visual Example

Browser Output Preview

9.3.2 onkeyup

The onkeyup attribute fires when the user releases a key on the keyboard[cite: 138]. By the time this event runs, the character is already inside the input field. This makes it perfect for formatting text (like auto-capitalization) or triggering a live search filter based on the final typed word[cite: 138].

Code Example

<p>This function transforms the character to upper case on release.</p>
Enter your name: <input type="text" id="fname" onkeyup="eventHandler()" />

<script>
  function eventHandler() {
    var x = document.getElementById("fname");
    x.value = x.value.toUpperCase();
  }
</script>

Visual Example

Browser Output Preview

9.3.3 onkeypress

The onkeypress attribute fires when a user presses a key that produces a character value (like letters or numbers)[cite: 139]. Note: In modern web development, this event is considered deprecated, and developers are encouraged to use onkeydown or oninput instead.

Code Example

<input type="text" onkeypress="eventHandler()" />

<script>
  function eventHandler() {
    alert("You pressed a key inside the input field");
  }
</script>

Section 9.4

Mouse Events

Mouse events are triggered when the user interacts with the webpage using a mouse[cite: 140]. These events are widely used to create interactive buttons, custom hover effects, drag-and-drop features, and dynamic UI controls.

9.4.1 onclick

The onclick attribute fires the moment a user clicks on an element[cite: 140]. It is the most common mouse event, used heavily for form submissions, opening modals, toggling menus, or confirming actions.

Code Example

<button onclick="eventHandler()">Click me</button>

<script>
  function eventHandler() {
    alert("You clicked the button");
  }
</script>

Visual Example

Browser Output Preview

9.4.2 ondblclick

The ondblclick attribute fires on a mouse double-click on the element[cite: 141]. This is useful for actions that require a deliberate double confirmation from the user, similar to opening a file on a desktop operating system.

Code Example

<button ondblclick="eventHandler()">Double Click me</button>

<script>
  function eventHandler() {
    alert("You double-clicked the button");
  }
</script>

Visual Example

Browser Output Preview

9.4.3 onmousemove

The onmousemove attribute fires repeatedly as long as the mouse pointer is moving while it is over an element[cite: 142]. This event is heavily used in drawing applications (like Canvas) or tracking the cursor to display custom tooltips[cite: 142].

Code Example

<p onmousemove="enlarge(this)">Move mouse over me!</p>

<script>
  function enlarge(x) {
    x.style["font-size"] = "24px";
  }
</script>

Visual Example

Browser Output Preview
Move your mouse pointer inside this box!

9.4.4 onmousedown and onmouseup

These two events break down a click into its two phases. onmousedown fires the moment a mouse button is pressed down, and onmouseup fires when the button is released[cite: 143]. Combining them allows you to create drag-and-drop systems or custom button pressing animations.

Code Example

<p id="p1" onmousedown="mouseDown()" onmouseup="mouseUp()">
  Click and hold this text!
</p>

<script>
  function mouseDown() {
    document.getElementById("p1").style.color = "red";
  }
  function mouseUp() {
    document.getElementById("p1").style.color = "blue";
  }
</script>

Visual Example

Browser Output Preview

9.4.5 onmouseover and onmouseout

The onmouseover attribute fires when the mouse pointer moves over an element, and onmouseout fires when the mouse pointer leaves it[cite: 144]. This is the JavaScript equivalent of the CSS :hover pseudo-class, giving you the power to change styles, images, or structure dynamically on hover[cite: 144].

Code Example

<p onmouseover="increaseFontSize(this)" onmouseout="decreaseFontSize(this)">
  Hover over me!
</p>

<script>
  function increaseFontSize(x) {
    x.style["font-size"] = "32px";
  }
  function decreaseFontSize(x) {
    x.style["font-size"] = "20px";
  }
</script>

Section 9.5

Clipboard Events

Clipboard events allow you to detect when a user copies, cuts, or pastes content within an element on your webpage. These are extremely useful for formatting data on paste, preventing copying of sensitive text, or showing custom alerts.

9.5.1 oncopy

The oncopy attribute fires when the user copies the content of an element[cite: 145]. There are two common ways to copy the content: pressing CTRL + C or right-clicking to select the "Copy" command[cite: 145].

Code Example

<input type="text" oncopy="eventHandler()" value="Try to copy this text" />

<script>
  function eventHandler() {
    alert("You copied the text.");
  }
</script>

Visual Example

Browser Output Preview

9.5.2 oncut

The oncut attribute fires when the user cuts the content of an element[cite: 146]. This usually happens by pressing CTRL + X or right-clicking and selecting the "Cut" command[cite: 146].

Code Example

<input type="text" oncut="eventHandler()" value="Try to cut this text" />

<script>
  function eventHandler() {
    alert("You cut the text.");
  }
</script>

Visual Example

Browser Output Preview

9.5.3 onpaste

The onpaste attribute fires when the user pastes some content into an element[cite: 147]. This is done by pressing CTRL + V or right-clicking and selecting the "Paste" command[cite: 147].

Code Example

<input type="text" onpaste="eventHandler()" placeholder="Try to paste text in here" />

<script>
  function eventHandler() {
    alert("You pasted the text.");
  }
</script>
